# 🎙️ つよつよ文字起こし＆議事録ツール (SimpleTranscriber)

音声・動画を投げるだけで、高精度な文字起こし・議事録・要約と考察が `output/` フォルダに整理されて出てくるローカルツールです。使うほど賢くなります。

## 特徴

- **「時刻・話者・発言」が一目でわかる表示**: 話者ごとに色分け、発話時間の割合つき。時刻をクリックするとその位置から音声を再生。
- **ワンクリックでダウンロード**: 文字起こし.md / 議事録.md / 字幕.srt をボタン1つで保存。
- **話者識別＋声紋登録**: pyannote（WhisperXと同じ話者分離エンジン）で単語単位に話者を割り当て。Hugging Faceトークン未設定時は自前の声紋クラスタリング（人数自動推定）。
  「👤 人物・声紋登録」タブで本人の録音（またはマイク録音）を登録すると、次回から自動で名前が付く。
- **高精度な文字起こし**: faster-whisper large-v3（GPU）＋人名・用語のホットワード、無音区間の誤認識（「ご視聴ありがとうございました」等）を自動除外。
- **句読点を自動で補う**: 話の「間」と文末表現から「、」「。」「？」を推定。音量の自動正規化で小さな声も拾いやすく。
- **AI校正**: gemma4:31b が誤変換を文脈で修正。推測で直した箇所は<span style="color:red">赤字</span>。時刻・話者の構造は崩さない。
- **議事録の自動作成**: 【会議概要】【要点サマリー】【議題別の詳細】【決定事項】【アクションアイテム】表【保留・検討事項】【AIの意見】の構成。長時間会議は区間ごとに要約してから作成。
- **字幕(SRT)編集**: 単語タイミングから読みやすい長さ・区切りで自動分割（1行文字数・行数・秒数を調整可）。
  時刻の一括ずらし、重なり・速すぎのチェック＆自動修正、既存SRT/VTTの読み込み、SRT/VTT保存。
- **使うほど賢くなる**: 発言の修正を保存すると誤認識を学習、話者の確定で声紋を蓄積。
- **完全ローカル動作（デフォルト）**: 文字起こしもLLM（Ollama）もPC内で完結。音声も動画も、複数ファイル一括もOK。
- **Word/PDF出力・横断検索**: 議事録を提出形式に変換、過去の全出力を全文検索。

## 起動方法

| OS | 方法 |
|----|------|
| Windows | `run.bat` をダブルクリック |
| Mac / Linux | ターミナルで `./run.sh`（初回は `chmod +x run.sh`） |

初回はライブラリの自動ダウンロードがあります（数分〜10分）。準備完了後、ブラウザで `http://127.0.0.1:7860` が開きます。

## LLM設定（議事録・要約・校正の頭脳）

「⚙️ 設定」タブで選択できます。**使う人次第で自由に選べます。**

| モード | 必要なもの | 特徴 |
|--------|-----------|------|
| **Ollama**（デフォルト） | [Ollama](https://ollama.com) をインストールし `ollama pull gemma4:31b` | 無料・完全オフライン・機密会議OK。gemma4最上位モデル |
| **Claude API** | APIキー（設定タブ or 環境変数 `ANTHROPIC_API_KEY`） | 最高品質 |
| **OpenAI API** | APIキー（設定タブ or 環境変数 `OPENAI_API_KEY`） | GPT系を使いたい人向け |
| 使わない | — | 文字起こしのみ実行 |

※ クラウドモードでは文字起こし**テキスト**が外部APIに送信されます（音声ファイル自体は送信されません）。

## 出力フォルダ構造

```
output/
└── 2026-07-16_1430_定例会議/
    ├── transcript.md      ← 文字起こし（時刻・話者・赤字付き＋話者ごとの発話時間）
    ├── transcript.srt/.vtt← 字幕ファイル（自動生成）
    ├── transcript_edited.srt ← 字幕編集タブで保存した字幕
    ├── utterances.json    ← 発言データ（「過去の結果を開く」で再編集できる）
    ├── audio.m4a          ← 再生用の軽量音声
    ├── 議事録.md          ← 議事録（決定事項・アクションプラン等）
    ├── 要約と考察.md      ← 3行要約・考察・ネクストアクション
    └── meta.json          ← 処理情報
```

## 話者識別・声紋登録

`run.bat` が自動でセットアップします（NVIDIA GPUがあればCUDA版PyTorchを自動インストール）。

**高精度（pyannote）を使うには**: Hugging Faceで [speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1) と [segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0) の利用規約に同意し、発行したトークン（Read）を「⚙️ 設定」に入れてください。未設定でも自前の方式で動きます。

1. 「👤 人物・声紋登録」タブで名前を入れ、その人だけが話している音声（10〜30秒）をアップロード or マイク録音 →「声紋を登録」
2. 以降の文字起こしでは、登録済みの人に自動で名前が付きます
3. 未登録の人は「話者A」等で表示されるので、「話者に名前を付ける」で名前を入れて確定すると声紋も保存されます
4. 話者数が分かっている場合は「話者の人数」を指定すると精度が上がります

話者の人数は声の特徴から自動推定します（上限は「⚙️ 設定」で変更可）。
結果がおかしい時は「話者の人数」を指定して「👥 話者識別だけやり直す」を押すと、文字起こしをやり直さずに数分で再計算できます。
別の人に名前が付く場合は「声紋一致のしきい値」を上げてください。

```

├── app.py               # Gradio UI（メイン）
├── core/                # 機能モジュール群
│   ├── transcriber.py   #   faster-whisper（GPU自動検出）

│   ├── diarization.py   #   話者分離・声紋登録
│   ├── utterances.py    #   発言の構造化・表示HTML・Markdown・字幕生成
│   ├── llm.py           #   Ollama / Claude / OpenAI 切替
│   ├── minutes.py       #   議事録・要約・校正の生成
│   ├── people.py        #   人物マスタ
│   ├── glossary.py      #   用語辞書・修正学習
│   ├── export.py        #   Word / PDF 変換
│   ├── search.py        #   横断全文検索
│   └── ...

├── profiles/            # 人物マスタ・声紋・用語辞書（成長データ）
```

## 対応入力形式

音声: mp3 / wav / m4a / ogg / flac / aac / wma / opus
動画: mp4 / mov / avi / mkv / wmv / flv / ts / m4v / webm

## 注意事項

- 終了時はブラウザを閉じるだけでなく、コマンドプロンプト（ターミナル）も閉じてください。
- `large-v3` はCPUだと非常に遅いため、GPU非搭載PCでは `small` / `medium` を推奨します（autoは自動選択）。
- ffmpeg が必要です（Windowsは同梱検出、Macは `brew install ffmpeg`）。

## 動作環境

- Windows / macOS / Linux
- Python 3.10+
- （推奨）NVIDIA GPU + CUDA
