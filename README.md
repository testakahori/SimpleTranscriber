# シンプル文字起こしツール (完全ローカルオフライン実行)

完全無料で使えて、音声データを外部に一切送信しないセキュアなローカル文字起こしツールです。
YouTubeの動画音声（mp4）や、会議の録音ファイル（mp3, wav）等から、テキストを抽出します。

## 🌟 特徴

- **完全ローカル動作:** 処理はすべてお使いのPC内で完結します。APIキー不要で、情報漏洩のリスクがありません。
- **長尺対応:** 数十分〜1時間以上の音声ファイルでも、無音区間を自動判定しハルシネーション（AI特有の幻覚・繰り返しバグ）を防ぐ安定設計になっています。
- **ワンクリック起動:** バッチファイル（`run.bat`）をダブルクリックするだけで、自動で環境構築からブラウザ画面の表示まで動作します。黒い画面で難しいコマンドを打つ必要はありません。

## 📥 インストール＆起動方法

1. **アプリの起動**
   フォルダ内にある `run.bat` をダブルクリックして実行してください。
2. **初回セットアップ（自動）**
   初回のみ、専用のプログラム実行環境(venv)の作成と、必要なライブラリ群のダウンロードが裏側で行われるため、**数分間〜10分程度**かかります。そのまま黒い画面を閉じずにお待ちください。（2回目以降はすぐに起動します）
3. **ブラウザ画面の表示**
   準備が完了すると、自動的にWebブラウザが立ち上がり、`http://127.0.0.1:7860` で文字起こしの操作画面が表示されます。

## 🎤 使い方

1. ブラウザで開いた画面の「音声ファイル」欄に、パソコン内の音声ファイル（mp3, wav, mp4など）をドラッグ＆ドロップするか、クリックしてファイルを選択します。
2. 「文字起こし開始」ボタンをクリックします。
   - ※初回実行時のみ、高精度のAIモデルファイル（数百MB〜1GB弱）のダウンロードが自動で走ります。
   - ※長時間の音声（30分〜）の場合、パソコンのスペックにもよりますが処理が完了するまでに数分〜十分以上かかることがあります。途中でエラーになったわけではありませんので、ブラウザのタブを閉じずにそのままお待ちください。
3. 処理が終わると、右側のテキストボックスに「文字起こしの結果テキスト」が表示されます。
4. すぐ下に表示されるダウンロードリンク (`transcription_result_xxxx.txt`) をクリックして、テキストデータを自身のパソコンに保存してください。

## ⚠️ 注意事項・制限事項

- ツールを終了する際は、ブラウザのタブを閉じるだけでなく、**必ず表示されている黒い画面（コマンドプロンプト）の右上の「×」ボタンを押して**閉じてください。これを閉じないと裏側でシステムが動き続けてしまいます。
- 処理中に「文字起こし結果」欄に何も出てこない時間帯が続いても、裏側の黒い画面には `処理進捗: [xxx.s -> yyy.s]` と現在の進行状況が表示されます。進行していれば正常に動いていますので、気長にお待ち下さい。
